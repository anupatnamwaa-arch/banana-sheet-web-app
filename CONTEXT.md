# Banana Sheet

A mobile-first personal-finance PWA. Users log money frictionlessly via phone home-screen shortcuts; the web app is a premium visualization dashboard.

## Language

### Experience

**Nana**:
The in-app banana companion and coaching voice inside Banana Sheet. Nana interprets money behavior in a friendly, shame-free tone; Nana is not the product name and not an AI chatbot persona.

**Nana Guidance**:
Financial meaning computed from deterministic money rules and expressed in Nana's friendly Thai-first voice. AI may enrich a Daily Brief or Monthly Reflection, but does not decide immediate safe-to-spend guidance.

**Daily Brief**:
Nana's stable daily interpretation of the user's money condition. It refreshes each morning and when deterministic rules detect a meaningful event, such as Income that may need allocation, an unusual Expense, a Category threshold crossing, a pace-status change, or an upcoming Fixed Expense.

**Safe to Spend**:
The flexible amount Nana considers safe to use today after protecting upcoming Fixed Expenses and committed saving, distributed across the days remaining in the current budgeting period. It is guidance for daily decisions, not an account balance.

**Banana Money Score**:
A 0-100 interpretation of the user's current money behavior. It supports Nana's Daily Brief and summarizes spending pace, Safe to Spend, saving progress, upcoming Fixed Expense pressure, and logging consistency without replacing the underlying metrics.

The domain has two strictly separate worlds of money that are never silently merged: **flow** (movement over time) and **stock** (a snapshot of what you own/owe).

### Flow (derived from Transactions)

**Transaction**:
A single movement of money, either an Income or an Expense. The atomic record users log. Lives in the `transactions` table.
_Avoid_: entry, record, purchase

**Expense**:
A Transaction where money goes out (`type = 'expense'`).
_Avoid_: spend, cost, payment

**Income**:
A Transaction where money comes in (`type = 'income'`).

**Net Saved**:
Cumulative `Income − Expense` within the selected period. A pure flow metric. Shown on the Overview as "Total Saving".
_Avoid_: savings, balance (these imply a bank/stock figure)

**Net Cash Flow**:
`Income − Expense` for the period. (Synonymous with Net Saved over the same period; "Net Cash Flow" emphasises the rate, "Net Saved" the accumulated total.)

### Access & Monetization

**Active** (Pro):
A user whose account has unlocked premium features. Computed, not just stored: `is_active = true AND (plan_expires_at IS NULL OR plan_expires_at > now())`. The owner sets `is_active` manually after verifying payment.
_Avoid_: paid, premium user (use "Active" / "Pro" for the state)

**Free user**:
A signed-up user who is not Active. Can log via Shortcut, see basic Overview (Total Expense, Net Cash Flow), use the transaction CRUD list, export CSV, and try the AI Roast once. Everything else (Emergency Runway, Daily Pace, Analytics tab, Wealth & Debt, Budgets, CSV Import) is gated.

**Plan**:
One of `lifetime` (no expiry), `yearly`, or `monthly` (both set `plan_expires_at`). Stored as `profiles.plan_type`. Verification is manual via Telegram; payment is a PromptPay QR (39 THB) or a Promo Code.

**Promo Code**:
A code a user enters to self-activate for free, backed by a `promo_codes` table (`code, is_active, max_uses, used_count`). A valid code sets the user Active, skipping the QR.

### Categorization

**Category**:
A user-owned label for grouping Transactions (Food, Transport, etc.). A controlled vocabulary, not free text — lives in a `categories` table, seeded on signup with presets that mirror the home-screen Shortcut's preset menu. Users can rename/add/delete. Budgets reference a Category; the Category Breakdown donut joins on it. Ingestion auto-creates a Category if the Shortcut sends an unrecognized name (so logging never fails), surfacing it as new for the user to merge/rename.
_Avoid_: tag, label, group

### Virality

**AI Roast**:
A 2-sentence Thai roast of the user's current-month spending, written in a chosen Persona's voice (Mama, Boss, Gen Z, Monk). Generated by an OpenAI nano-tier model (GPT-5 nano) from *aggregated* monthly data only (category totals, top categories, net cash flow, biggest-category) — never raw Transaction rows. Rendered on a 9:16 share card with a "Roasted by Banana Sheet" watermark, exported via `html-to-image`. Free users get 1 lifetime roast; Active users get 1 per 7 days.

**Persona**:
The voice/character the AI Roast is written in. A fixed preset list (Mama, Boss, Gen Z, Monk).

**Saving Rate**:
`Net Saved / Total Income` for the selected period, shown as a percentage. Displays "—" when period Income is zero.

**Daily Pace**:
A within-month progress indicator: this month's cumulative Expense vs. a linear pace line = `total monthly budget × (days elapsed / days in month)`, bucketed in Asia/Bangkok. Under pace = good, over = warning. Falls back to trailing Avg Monthly Expense as the target when no Budgets are set.

**Brand**:
A merchant/service (Netflix, Starbucks, Grab) that a Transaction can be matched to, purely for visual polish — its logo shows on the dashboard instead of a generic category icon. Lives in a single **shared, global** `brands` catalog (`name, aliases, domain, logo_url`), curated by the owner, not per-user. A Transaction's `note` is auto-matched against brand names/aliases on ingest to set an optional `brand_id`; unmatched Transactions fall back to the Category icon. Logos are served from a logo CDN by domain, not hosted by us.
_Avoid_: merchant, vendor, store (use "Brand")

### Stock (derived from Wealth & Debt)

**Net Worth**:
`Sum(Assets) − Sum(Liabilities)` from the `wealth_debt` table. Manually maintained, decoupled from Transactions.

**Asset**:
Something the user owns with a current value (`type = 'asset'`).

**Liability**:
Something the user owes (`type = 'liability'`).
_Avoid_: debt (use "Liability" for the record; "Debt" only in the tab name)

**Emergency Runway**:
How many months the user could survive on what they *have*: `liquid Assets / Avg Monthly Expense`. A stock-based metric — its numerator comes from the Wealth world, NOT from cumulative Transactions.

**Liquid Asset**:
An Asset flagged (`is_liquid = true`) as available emergency cash (cash, savings accounts). Only Liquid Assets count toward Emergency Runway; illiquid assets (property, vehicles) are excluded.

**Avg Monthly Expense**:
Average monthly Expense over an adaptive trailing window: use up to the trailing 12 months of data, falling back to 6, then 3, then all-available when the user has less history.
